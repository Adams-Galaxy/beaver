# Beaver

A personal, modular, long-lived Linux desktop environment built around a
programmable desktop core, a reactive shell frontend, and a tiling compositor.

Not a Hyprland configuration. Hyprland is the compositor, Quickshell is the
frontend, and a Rust daemon is the desktop core — each replaceable without the
project ceasing to be itself.

**Status: conceptual design. No implementation yet.**

The design lives in [`journal/`](journal/). Start with
[`journal/README.md`](journal/README.md) for how the documentation works, then
[`journal/STATUS.md`](journal/STATUS.md) for where the project currently stands.
